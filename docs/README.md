# docs/

Notas de desarrollo de esta app: roadmap de features, decisiones técnicas, y contexto que no
vive en el código. No confundir con el conocimiento operativo del negocio (reglas de sauna,
química de jacuzzi, contactos de proveedores, estilo de mensajes) — eso vive en el skill de
usuario `airbnb-manager` (`~/.claude/skills/airbnb-manager/`), independiente de este repo.

Sugerencia de organización a medida que se agreguen notas:

- `roadmap.md` — próximas features / prioridades
- `decisions/` — decisiones técnicas puntuales (una nota corta por decisión, con fecha y motivo)
